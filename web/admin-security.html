Կապել authenticator հավելվածը

Օգտագործեք առանձին authenticator հավելված կամ գաղտնաբառերի պաշտպանված կառավարիչ։ Երկրորդ գործոնը պետք է պահվի հիմնականից առանձին վայրում։

Եթե չեք կարող սկանավորել, ձեռքով մուտքագրեք այս գաղտնիքը.

ՎԵՐԱԿԱՆԳՆՄԱՆ ՊԱՏՐԱՍՏՎԱԾՈՒԹՅՈՒՆ

Կապված գործոններ

Supabase Auth-ը վերականգնման կոդեր չի տրամադրում։ Պահուստային երկրորդ գործոնը master admin-ի վերականգնման հիմնական միջոցն է։

ՎԵՐԱԿԱՆԳՆՄԱՆ ԿԱՆՈՆՆԵՐ

Հաշվի կորուստ կամ փոխարինում

  1. Գաղտնաբառը վերականգնվում է միայն հաստատված էլ. հասցեով, ապա պահանջվում է MFA։
  2. Կորած հիմնական գործոնի դեպքում օգտագործվում է պահուստային գործոնը։
  3. Բոլոր գործոնների կորստի դեպքում վերականգնումը կատարում է երկրորդ ակտիվ master admin-ը կամ փաստաթղթավորված Supabase owner ընթացակարգը։
  4. Վերականգնումից հետո հին սեսիաները չեղարկվում են, գաղտնաբառը փոխվում է և MFA-ն վերակապվում է։
  5. Master admin հաշիվը չի ջնջվում. պատասխանատվությունը փոխանցելուց հետո այն կարող է միայն դադարեցվել կամ փոխել դերը։
