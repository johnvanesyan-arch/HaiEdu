# Sprint 6 test plan

Use an authenticated student account after Chapter I practice.

## A — eligibility
1. Confirm Mastery Check is locked while one or more skills are incomplete.
2. Complete the remaining practice skills.
3. Confirm the dashboard changes to **Mastery Check ready**.

## B — independent assessment
1. Start Mastery Check.
2. Confirm the counter is 1/20 through 20/20.
3. Confirm no Help button appears.
4. Submit wrong and correct answers deliberately.
5. Confirm correctness is not revealed during the check.
6. Confirm no exact item repeats within the check.

## C — pass criteria
1. Verify an 80%+ result with at least 1/2 in every skill passes.
2. Verify a result above 80% still fails if any skill is 0/2.
3. Confirm a passing result marks the unit complete.

## D — retry rules
1. Produce a failed Mastery Check.
2. Confirm immediate retry is blocked.
3. Confirm the dashboard lists required remediation skills.
4. Complete a bounded practice session for each required skill.
5. Confirm retry becomes available only after those sessions are complete.

## E — spacing
1. Compare the Mastery Check item codes against the most recent practice items.
2. Confirm least-recent/unseen items are preferred where the bank has alternatives.
