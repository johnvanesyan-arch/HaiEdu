## Purpose

This review is the publication gate for the first platform skill graph. The reviewer is **not** being asked to proofread software. The objective is to determine whether the platform has decomposed Chapter I into pedagogically valid, appropriately sequenced Grade 7 skills.

For each skill, mark:

- **Keep** — suitable as defined;
- **Modify** — concept is needed but scope/name/description should change;
- **Split** — skill is too broad;
- **Merge** — skill is too narrow or overlaps another;
- **Remove** — should not be independently tracked.
