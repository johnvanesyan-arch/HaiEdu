## Projection and authorization

`get-teacher-workspace` accepts selectors only: optional assignment ID, work ID, a keyset cursor and up to four recent class IDs. `teacher-workspace-v1` returns 12 queue entries, at most six class cards, a snapshot timestamp and explicit coverage/card pagination metadata. Counts span all currently authorized active writable school contexts, or the exact selected assignment. Failed reads show unknown data with retry, never a fabricated zero. Legacy schoolless cards explicitly have unavailable writing counts.

The Edge derives actor/session from a verified credential and rechecks live session and teacher profile before return. The service-only private reader checks current teacher role, session, school membership, assignment, year, subject grant, programme and release. Its public wrapper is SECURITY INVOKER. Direct browser roles cannot execute either reader. The private function needs SECURITY DEFINER because service_role cannot read Auth session tables; it exposes only this bounded metadata contract. Response text, drafts, answers and feedback never enter Today responses or browser storage. Inspecting/reviewing the response still passes the existing writing service's final context and revision checks.

Class artwork follows governed subject codes and the existing shared artwork registry, including its generic fallback. This adds no subject/grade-specific logic. Class cards link to exact class/assignment routes; count buttons filter the queue. Recent class hints contain at most four UUIDs in this tab's sessionStorage, keyed to the authenticated teacher. They are reauthorized on every read, cleared on sign-out/account switch, and cannot confer access. No learner content is cached persistently. Async response guards and disposal prevent an old account, class or request from restoring private work; unsaved feedback retains the existing navigation guard.
