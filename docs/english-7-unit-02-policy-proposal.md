## Proposed learner rules

| Area | Proposed Unit 2 rule |
| --- | --- |
| Diagnostic | One completed 24-question baseline; DA/DB give two eligible candidates, including a possible technical replacement. No pass/fail; completion unlocks core Practice. |
| Mastery scoring | 24 equal-weight single-choice items; one point each, no negative marking. Submit all responses. At least 80% using the unrounded score: **20/24** is the smallest attainable pass (83.33%); 19/24 fails. |
| Skill safeguard | S01/S02: at least **2/3** each. S05 passive and S09 past-aspect: **3/4** each. S07/S10/S11/S12/S13: **1/2** each. Both overall and all skill minima must pass. |
| Reporting | Vocabulary/expressions 6, grammar 10, reading 4, listening 4. This is bounded automatic evidence, not complete English competence or CEFR certification. |
| First Mastery readiness | All nine core skills ready. Within each skill: model score ≥0.75 with at least three evidence records **or** at least three distinct items encountered and the latest three answers fully correct without hints. |
| Practice | Up to eight questions per session, whole shared-source groups, early completion when eligible supply is exhausted; unseen-first followed by governed repeats. Exactly 47 core items. |
| Review | Twelve planned core Practice questions after the first and second scored failures, using existing completion/help requirements; no additional review pass percentage. No assessment sources moved into Review. |
| Attempts | At most three scored Mastery attempts using MA/MB/MC; required review between failures. Review remains available after final failure, without a fourth attempt. |
| Audio | Two shared plays per assessed recording, normal speed, no transcript; two questions sharing a recording share the allowance. Unlimited Practice/Review replay. |
| Technical interruption | Resume saved state first. Supported persistent audio failure can end unscored, retain responses/exposure and use an unused eligible whole form. No exposed-form reset or automatic failure when forms run out. |
| Writing | Accepted W01: one 80–100-word response, four criteria scored 0–3, separate /12 feedback. No automatic readiness/pass gate or numerical writing pass threshold. Pending teacher review is not zero/failure. |
| Speaking and timing | Speaking remains classroom-assessed. No assessment timer or invented completion-time estimate. |

The recommendations deliberately reuse the existing English mechanisms after checking Unit 2's actual shape. The overall threshold discourages large gaps; per-skill minima prevent a strong total hiding a missing strand. Four-question grammar samples require three correct, three-question vocabulary samples require two, and two-question comprehension samples require one. These are provisional product criteria, not ministry-prescribed thresholds or empirically calibrated mastery.

The proposed model retains alpha=2, beta=2, minimum evidence=3, flat difficulty weight, hinted positive multiplier=0.65 and no discount to negative evidence. Normalized partial scores can update the model during Practice; the current assessment forms have no partial-credit items. Four perfect unhinted responses from the prior reach 0.75; the recent-answer route can qualify earlier. Scores below 0.5 indicate support, below 0.75 development and at least 0.75 security, subject to minimum evidence. Existing session selection/help rules are retained in the JSON model. A separate scoped immutable configuration must be compiled after acceptance; Unit 1 identities are not rebound.

The three core listening Practice questions share **The Power of Music**. Diagnostic plus Practice offers three distinct gist items and four detail items, making the proposed recovery route structurally attainable. The model route can use governed repetitions. This is limited evidence: neither repeated answers nor multiple questions from one source establish independent listening coverage. The existing recovery function counts distinct items over the release history, not necessarily within its latest-three-answer window. A learner can therefore satisfy that route with repeated recent items after encountering three distinct items. Valid answers retained after an unscored technical exit can also contribute. These semantics are explicit in this proposal and are not changed in this slice.

The other **25 Practice items** remain accepted: twelve supporting grammar, six present-perfect extension and seven optional/supporting listening items. They stay outside the automatic core Practice/Review pool. A separate non-gating route is not yet implemented; this proposal does not claim that all 72 are immediately available through learner sessions. In particular, optional listening shares core skill IDs, so admitting it to the same evidence model would contaminate readiness. Preserve versions and textbook positions; do not silently remap, delete or promote it.
