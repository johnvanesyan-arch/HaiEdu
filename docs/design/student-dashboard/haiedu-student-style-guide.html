Font and content rules

Noto Sans Armenian, then Noto Sans, Arial and the system sans-serif fallback.

  • The preview names the font but does not bundle it. Verify actual production font delivery and glyph coverage.
  • Use 16 px body/input text, 14 px metadata and 12 px only for short nonessential captions.
  • Use rem units. Let long Armenian labels wrap; do not shrink them to fit.
  • No forced uppercase or negative tracking on Armenian UI text.
  • Use language attributes for Armenian UI and English or other course passages.

Up to 820 px work column. Reserve space for mobile navigation and safe-area insets.

Thresholds are starting points from the review, not fixed device categories. Acceptance still needs actual 360/768/1280 px viewports, 200% zoom and a 320 CSS-pixel reflow check.

Resource cards show a goal, topic, format and provenance. Time estimates or recommendations appear only when explicitly supplied.

Listening uses visible controls and policy-derived allowances, without autoplay. Writing shows draft, save, submission and teacher-feedback states separately.

07

Motion with a purpose

Short feedback helps explain a change. Movement never carries essential meaning.

This switch affects only this specimen. Operating-system reduced-motion preferences are also respected.

Քայլ առ քայլ՝ առաջ

Փոքր փոփոխություն, հստակ հաջորդ քայլ։

Motion limits

120–160 ms

Button, background and lightweight interaction feedback.

About 200 ms · once

Entry or disclosure decoration. Hover lift stays within 2 px.

Reduced motion

No decorative movement; state changes remain immediate. No autoplay, parallax, perpetual bounce or confetti.

08

Ready to guide implementation

The selected direction is documented. Production integration and acceptance remain separate work.

Before a student-interface release

  • Apply tokens consistently across every affected student surface.
  • Use 4.5:1 for ordinary text and 3:1 for essential non-text cues under the applicable WCAG criteria.
  • Check keyboard focus, dialogs, field errors and status announcements.
  • Verify Armenian wrapping, font delivery, actual viewports, zoom and reflow.
  • Preserve the 45 mapped capabilities, authorization and learning-policy boundaries.
  • Complete required CI, exact-production and four-subject acceptance.

What this guide does not switch on

New subject releases, altered assessment rules, stored themes, XP, streaks, avatar uploads, AI helpers or unsupported aggregate progress.

Future account features receive a layout position only when their service and access rules are ready. Supplementary materials still need their authoring and protected-delivery slice.

Implementation order: shared shell/Home/course navigation, then course/assessment/progress and work/account surfaces. English remains paused after C47.
