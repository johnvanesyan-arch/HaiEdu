# Sprint 15B.7 — Ֆիզիկա 7, Գլուխ II-ի հինգերորդ հարցերի ընտանիք

**Կարգավիճակ՝** հարցերի բովանդակային ստուգումն ավարտված է, և բոլոր չորս ընթացիկ տարբերակները հաստատված են։ Հարցերը շարունակում են սովորողին անհասանելի մնալ։ Թյուրիմացությունների սահմանումները և օգնության ուղեցույցը սևագիր են, իսկ արտաքին մասնագիտական ստուգումը մնում է սպասման մեջ։

## Որոշում

Հինգերորդ ընտանիքի համար ընտրվել է `PHY7-U02-S06 — Դիֆուզիան բացատրել օրինակներով` հմտությունը։ Այն ուղղակիորեն համադրված է Թեմա 2-ի պարտադիր վերջնարդյունք 1(4)-ին և հաջորդում է մասնիկների անընդհատ ու անկանոն շարժման (`S05`) ընտանիքին։

| Դաշտ | Արժեք |
|---|---|
| Ընտանիք | `PHY7-U02-S06-F01-DIFFUSION-EXAMPLES` |
| Ձևանմուշ | `PHY7-U02-S06-T01-EXPLAIN-DIFFUSION` |
| Հմտություն | `PHY7-U02-S06` |
| Ծրագրային կապ | Թեմա 2, պարտադիր վերջնարդյունք 1(4), ուղղակի համադրում |
| Դասագրքային աղբյուր | «Ֆիզիկա 7» (2023), Գլուխ II, §10, տպագիր էջեր 30–32, նկարներ 30–31 |
| Կառուցույթ | դիֆուզիայի սահմանում, ինքնաբերական խառնում, մասնիկների անկանոն շարժում և փոխադարձ ներթափանցում՝ փորձարարական, առօրյա ու բնության օրինակներում |
| Կարգավիճակ | fixed հեղինակային կատալոգ, հարցերը `published / approved`, սովորողին անհասանելի |

## Աղբյուրային սահմաններ

Ընտանիքը հիմնված է §10-ի հետևյալ պնդումների ու օրինակների վրա.

1. դիֆուզիան նյութերի ինքնաբերական խառնումն է,
2. խառնումը պայմանավորված է մասնիկների անընդհատ ու անկանոն շարժմամբ և միմյանց միջմոլեկուլային տարածություններ ներթափանցմամբ,
3. ջրի և պղնձարջասպի լուծույթի սկզբնական սահմանը ժամանակի ընթացքում անհետանում է առանց արտաքին խառնելու,
4. աղաջրում լուծված աղի մասնիկները ներթափանցում են բանջարեղենի մեջ,
5. թոքերում թթվածինը օդից անցնում է արյան մեջ դիֆուզիայի միջոցով։

Գազերում, հեղուկներում ու պինդ մարմիններում դիֆուզիայի արագությունների համեմատությունը դիտավորյալ չի գնահատվում. այն `PHY7-U02-S07`-ի կառուցույթն է։ Ջերմաստիճանի և դիֆուզիայի արագության կապը պահվում է `S08`-ի, իսկ ջերմաչափի աշխատանքի բացատրությունը՝ `S09`-ի համար։

## Սևագիր հարցեր

| Կոդ | Ստուգվող գործողություն | Ճիշտ պատասխան |
|---|---|---|
| `I01` | սահմանել դիֆուզիան | նյութերի ինքնաբերական խառնում՝ մասնիկների փոխադարձ ներթափանցմամբ |
| `I02` | բացատրել պղնձարջասպի լուծույթի և ջրի փորձը | երկու հեղուկների մոլեկուլները անկանոն շարժմամբ փոխադարձաբար ներթափանցում են |
| `I03` | բացատրել աղի ներթափանցումը բանջարեղենի մեջ | լուծված աղի մասնիկների շարժմամբ իրականացվող դիֆուզիա |
| `I04` | բացատրել թթվածնի անցումը օդից արյան մեջ | թթվածնի մասնիկների ներթափանցում դիֆուզիայի միջոցով |

Յուրաքանչյուր հարց ունի չորս պատասխանային տարբերակ, մեկ պատասխանային բանալի, Գլուխ II-ի ծրագրային ընդգրկում, ամբողջ գնահատելի բովանդակությունից հաշվարկված իմաստային մատնահետք և տարբերակ 1-ի անփոփոխ նկար։ Կանոնական ճիշտ պատասխանները նախապես հավասարակշռված են՝ `A/B/C/D` դիրքերից յուրաքանչյուրը մեկ անգամ, իսկ սովորողին մատուցելիս պատասխանների հերթականությունը շարունակում է խառնվել գործող սերվերային կանոնով։

## Թյուրիմացությունների մոդել

Ստեղծվում են չորս սևագիր սահմանումներ.

1. դիֆուզիան միայն արտաքին խառնումով հնարավոր համարելը,
2. դիֆուզիան նյութի ամբողջական շերտի տեղաշարժ համարելը,
3. տեսանելի փոփոխությունը մասնիկների տեղափոխությունից անջատելը,
4. դիֆուզիան վիճակի կամ քիմիական փոփոխության հետ շփոթելը։

Բոլոր տասներկու սխալ պատասխանները համադրված են մեկ թյուրիմացության հետ։ Ձևանմուշը կիրառում է `all_distractors` քաղաքականությունը, ուստի հետագա հրապարակումը կամ համադրումների փոփոխությունը չի կարող շրջանցել ամբողջականության դարպասը։

## Օգնության սևագիր

Ստեղծվում է մեկ ձևանմուշային ուղեցույց՝ հետևյալ հաջորդականությամբ.

1. ստուգել՝ կա՞ ինքնաբերական խառնում առանց արտաքին խառնման,
2. նշել երկու նյութերի մասնիկների անընդհատ ու անկանոն շարժումը,
3. բացատրել մասնիկների փոխադարձ ներթափանցումը,
4. տեսանելի արդյունքը կապել հենց մասնիկային շարժման հետ,
5. տարբերակել դիֆուզիան շերտի ամբողջական տեղաշարժից, վիճակի փոփոխությունից և քիմիական ռեակցիայից։

Ուղեցույցը պահվում է և՛ ընթացիկ սևագրի աղյուսակում, և՛ անփոփոխ հեղինակման պատմության մեջ։ Ձևանմուշային պատմության պատկերը պարունակում է միայն տվյալ շրջանակին համապատասխան `triggerErrorCode` դաշտը և չի պահում հմտության ուղեցույցներին պատկանող `misconceptionCode` դաշտը։ Այն սովորողին հասանելի չի դառնում մինչև պաշտպանված `draft → review → published` ընթացքը։

## Անվտանգության սահման

Այս հատվածը չի ստեղծում գնահատման ավազան, գնահատման ձևանմուշ, փորձնական կարգավիճակ կամ սովորողի թողարկում։ Գլուխ I–II թեկնածու թողարկումը մնում է `draft`։ Հարցերը `published / approved` են միայն հեղինակային կառավարման շերտում, ունեն `learnerVisible=false` վիճակ և գնահատման որևէ ավազանի հետ կապված չեն։

## Բովանդակային վերանայում

Ապրանքի սեփականատերը 2026-10-01-ին ստուգել և հաստատել է բոլոր չորս հարցերն ու պատասխանները։ Արտադրական միջավայրում յուրաքանչյուր ընթացիկ տարբերակ `published / approved` է և ունի անցած տեխնիկական QA՝ առանց սխալների կամ զգուշացումների։ Տասներկու սխալ-պատասխանային համադրումները պահպանված են։ Թյուրիմացությունների չորս սահմանումները և օգնության ուղեցույցը մնում են սևագիր և առանձին վերանայման ենթակա, իսկ արտաքին մասնագիտական ստուգումը դեռ սպասման մեջ է։
