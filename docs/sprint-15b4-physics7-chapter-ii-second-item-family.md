# Sprint 15B.4 — Ֆիզիկա 7, Գլուխ II-ի երկրորդ հարցերի ընտանիք

**Կարգավիճակ՝** սովորողին անհասանելի կառավարվող բովանդակություն։ Հարցերը հաստատվել էին արտադրանքի պատասխանատուի կողմից, սակայն ճիշտ պատասխանների դիրքերի հետագա ամբողջականության ուղղումից հետո `I02`–`I04` նոր տարբերակները կրկին պահանջում են տեխնիկական QA և մարդու հաստատում։ `I01`-ը պահպանում է իր հաստատված տարբերակը, իսկ արտաքին մասնագիտական ստուգումը մնում է սպասման մեջ։

## Որոշում

Երկրորդ ընտանիքի համար ընտրվել է `PHY7-U02-S03 — Տարբերակել ատոմը, մոլեկուլը և քիմիական տարրը` հմտությունը։ Այն `PHY7-U02-S02`-ի անմիջական հաջորդն է և նախապայման է մոլեկուլների չափերի (`S04`) ու մասնիկների շարժման (`S05`) հետագա աշխատանքի համար։ Այս հերթականությունը թույլ չի տալիս չափերի կամ շարժման հարցերով շրջանցել հիմնական հասկացությունների տարբերակումը։

| Դաշտ | Արժեք |
|---|---|
| Ընտանիք | `PHY7-U02-S03-F01-ATOM-MOLECULE-ELEMENT` |
| Ձևանմուշ | `PHY7-U02-S03-T01-CLASSIFY` |
| Հմտություն | `PHY7-U02-S03` |
| Ծրագրային կապ | Թեմա 2, պարտադիր վերջնարդյունք 1(1), աջակցող համադրում |
| Դասագրքային աղբյուր | «Ֆիզիկա 7» (2023), Գլուխ II, §8, տպագիր էջեր 26–28 |
| Կառուցույթ | Ատոմի, մոլեկուլի և քիմիական տարրի դասակարգում ու հարաբերությունների տարբերակում |
| Կարգավիճակ | սևագիր fixed հեղինակային կատալոգ, վերանայման կարիք ունի, սովորողին անհասանելի |

## Աղբյուրային սահմաններ

Ընտանիքը հիմնված է §8-ի հետևյալ պնդումների վրա.

1. ատոմները մարմինները կազմող ամենափոքր «շինարարական տարրերն» են,
2. միևնույն տեսակի ատոմներից բաղկացած նյութը կոչվում է տարր,
3. երկու կամ ավելի միացած ատոմներից կազմված կայուն մասնիկը մոլեկուլ է,
4. մոլեկուլը կարող է կազմված լինել ինչպես նույն, այնպես էլ տարբեր տեսակի ատոմներից,
5. `H₂`-ը նույն տեսակի երկու ատոմից կազմված մոլեկուլ է, իսկ `H₂O`-ն՝ տարբեր տեսակի ատոմներից կազմված մոլեկուլ։

Ատոմների և մոլեկուլների չափերի համեմատությունը դիտավորյալ չի ներառվել. դա `PHY7-U02-S04`-ի առանձին կառուցույթն է։

## Սևագիր հարցեր

| Կոդ | Ստուգվող տարբերակում | Ճիշտ պատասխան |
|---|---|---|
| `I01` | մեկ `H` մասնիկ | ջրածնի ատոմ |
| `I02` | `H₂` | նույն տեսակի երկու ատոմից կազմված մոլեկուլ |
| `I03` | `H₂O` | մոլեկուլը կարող է կազմված լինել տարբեր տեսակի ատոմներից |
| `I04` | քիմիական տարրի սահմանում | միևնույն տեսակի ատոմներից բաղկացած նյութ |

Յուրաքանչյուր հարց ունի չորս պատասխանային տարբերակ, մեկ պատասխանային բանալի, Գլուխ II-ի ծրագրային ընդգրկում, ամբողջ գնահատելի բովանդակությունից հաշվարկված իմաստային մատնահետք և տարբերակ 1-ի անփոփոխ նկար։ Պատասխանների հերթականությունը կարող է խառնվել գործող սերվերային կանոնով։

## Թյուրիմացությունների մոդել

Ստեղծվում են հինգ սևագիր սահմանումներ.

1. ատոմն ու մոլեկուլը նույնացնելը,
2. ատոմն ու քիմիական տարրը նույնացնելը,
3. քիմիական տարրն ու մոլեկուլը նույնացնելը,
4. մոլեկուլի ատոմային կազմը սխալ սահմանելը,
5. մոլեկուլ կազմելիս ատոմների տարրային պատկանելությունը փոխված համարելը։

Բոլոր տասներկու սխալ պատասխանները համադրված են մեկ թյուրիմացության հետ։ Ձևանմուշը կիրառում է `all_distractors` քաղաքականությունը, ուստի հետագա հրապարակումը կամ համադրումների փոփոխությունը չի կարող շրջանցել ամբողջականության դարպասը։

## Օգնության սևագիր

Ստեղծվում է մեկ ձևանմուշային ուղեցույց՝ հետևյալ հաջորդականությամբ.

1. որոշել՝ ներկայացված է մեկ ատոմ, թե միացած մի քանի ատոմ,
2. հաշվել ատոմների տեսակները,
3. տարբերակել մասնիկը (ատոմ կամ մոլեկուլ) նյութի տեսակից (քիմիական տարր),
4. ստուգել եզրակացությունը `H₂` և `H₂O` օրինակներով։

Ուղեցույցը պահվում է և՛ ընթացիկ սևագրի աղյուսակում, և՛ անփոփոխ հեղինակման պատմության մեջ։ Այն սովորողին հասանելի չի դառնում մինչև պաշտպանված `draft → review → published` ընթացքը։

## Անվտանգության սահման

Այս հատվածը չի ստեղծում գնահատման ավազան, գնահատման ձևանմուշ, փորձնական կարգավիճակ կամ սովորողի թողարկում։ Գլուխ I–II թեկնածու թողարկումը մնում է `draft`, իսկ նոր հարցերն ունեն `draft / needs_review / learnerVisible=false` վիճակ։

## Բովանդակային վերանայում

Հաջորդ քայլը մարդու կողմից բոլոր չորս հարցերի, պատասխանների, տասներկու սխալ-պատասխանային համադրումների և օգնության ուղեցույցի ստուգումն է։ Միայն այդ որոշումից հետո կարող է սկսվել տեխնիկական QA-ն և յուրաքանչյուր նյութի հաստատման պաշտպանված ընթացքը։
