## Independent choices

Teacher source type: editable text, private PDF attachment, or HTTPS link. Every task has a title and plain-language instructions. Paste/type editing supports paragraphs, headings, lists and links; approved course tasks remain reusable without modifying their governed source.

Teacher-required student response type is independent: HaiEdu text editor, document upload, or link submission. Document requirements specify PDF, Word (DOCX), or both. The source format never implicitly selects the response format. Every source/response pairing is supported. Links are submitted explicitly and students receive an access-sharing reminder. There are no fabricated automatic completion, deadline, notification or grading features.

## Teacher flow

Prepare title/instructions → choose Text/PDF/Link source → choose required response type → feedback only or explicit assessment criteria → student preview → class/selected recipient summary → explicit send and durable receipt. Show only relevant fields; fold optional settings. Save private teacher drafts and support reuse as a new editable draft. Published/sent definitions and recipient snapshots are immutable; changes require a new version, not silent alteration of assigned instructions. Reuse never copies learner responses or feedback. Copying pins a saved source revision, saves one separate editable draft and retains a ready private PDF only within the same owner/assignment/release/unit context; it never replaces its bytes. Versioned task formatting and legacy literal text share the [reuse/format contract](teacher-task-reuse-formatting.md).

The existing published-task assignment path remains available and preserves course-writing prerequisites, separate human scores, immutable task versions and previous learner work. Teacher-created tasks are their own governed assignment workspaces; they do not masquerade as approved curriculum tasks, modify bank approvals or alter mastery/readiness rules.

## Student flow

My work → assigned task → explicit required response instruction → private draft → Submit → immutable submission → teacher feedback → returned revision → new submission. Uploading a file, entering text or pasting a link alone never submits it. Keep previous versions and published feedback. A submitted version cannot be overwritten. State labels are Draft, Submitted, Returned for revision and Reviewed; an empty review queue is not an invented completion.

## Review and access

Graded tasks use the assigned criterion version; private feedback drafts remain teacher-only and publication is explicit. Returns require actionable feedback; regrading requires a reason. Existing work and feedback are retained when a delivery is canceled.

All reads, uploads, downloads, sends, submissions and reviews require live actor, school, class, programme, year and recipient authorization.
