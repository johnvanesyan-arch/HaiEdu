# Sprint 5 acceptance criteria

- [x] Practice remains bounded to 8 questions maximum.
- [x] Dashboard can target a specific skill.
- [x] Desired difficulty reacts to mastery.
- [x] One error lowers target difficulty.
- [x] Repeated errors trigger bridge mode.
- [x] Unseen questions are preferred.
- [x] Immediate exact-item repetition is avoided.
- [x] Mistakes can return after spacing rather than immediately.
- [x] Same-item repetition is capped while alternatives exist.
- [x] Progressive Hint 1 / Hint 2 / worked-example support exists.
- [x] Help is available before answering and after an incorrect answer.
- [x] Current answer keys remain server-side.
- [x] Hint use is server-authoritative.
- [x] Assisted correct answers receive reduced positive evidence.
- [x] Recent recovery requires independent answers.
- [x] Remediation events and scheduler selection modes are persisted for analysis.
- [x] Ten Chapter I remediation guides are available.
- [x] Core scheduler tests are included in CI.
